# بوابة العَرَنْجِيَّة — فحص آلي ويدوي

> **الغرض:** تحويل «نبذ العرنجية» من نصيحة إلى **بوابة قابلة للقياس**. لا يكفي أن تقول «لا تستعمل من خلال»؛ يجب أن تفحص النص، وتحصي، وتحكم.
>
> **المرجع:** `arabic-writing-skill` — «العَرَنْجِيَّة» لأحمد الغامدي، والأبواب ٢–٤ من `SKILL.md`.

---

## ١. ما الذي تفحصه البوابة؟

| الفئة | أمثلة | الوزن |
| :--- | :--- | :--- |
| **أدوات وصل مصطنعة** | `من خلال`، `على صعيد`، `في إطار`، `حيث أن`، `فيما يتعلق بـ` | عالٍ |
| **أفعال مساعدة فارغة** | `قام بـ`، `أجرى`، `لعب دوراً`، `شكّل خطراً`، `أعطى وعداً` | قاطع |
| **مبني للمجهول مع فاعل معلوم** | `تم توقيع… من قبل`، `بواسطة` | قاطع |
| **استعارات مترجمة** | `ضوء أخضر`، `غسيل دماغ`، `عكس مشاعر`، `تبنّى فكرة` | عالٍ |
| **حشو إعلامي** | `تجدر الإشارة إلى`، `من الجدير بالذكر`، `في نهاية المطاف` | عالٍ |
| **تفضيل متكلَّف** | `الأكثر أهمية`، `الأقل وضوحاً` | متوسط |
| **ظرف/وصف عام** | `بشكل كبير`، `بصورة واضحة`، `على مستوى` | متوسط |

## ٢. كيف تُقاس؟

### ٢.١ المؤشر

```text
المؤشر = مجموع أوزان المخالفات لكل ١٠٠٠ كلمة
وزن القاطع = ٣، والعالٍ = ٢، والمتوسط = ١
```

### ٢.٢ الحكم

| المؤشر | الحكم | الإجراء |
| :--- | :--- | :--- |
| صفر، ولا مخالفة قاطعة | **ناجح** | لا تعديل |
| أقل من ٣، ولا قاطع | **ناجح بملاحظات** | اقتراحات أسلوبية فقط |
| ٣–٨، أو قاطع واحد | **يحتاج مراجعة** | أعد صياغة المواضع |
| أكثر من ٨، أو قاطعان | **راسب** | أعد بناء النص، لا تُجمّله |

**قاعدة:** المخالفة القاطعة لا تُقبل ولو كانت واحدة. `تم توقيع الاتفاقية من قبل الوزيرين` لا تُشفع لها بقية النص الفصيح.

## ٣. الفحص الآلي

```bash
python scripts/check_calques.py article.md
python scripts/check_calques.py article.md --json
python scripts/check_calques.py article.md --strict   # يخرج بـ1 عند الرسوب
```

**ما يفعله السكربت:**

1. يقرأ النص.
2. يطابق قائمة أنماط العرنجية.
3. يحسب المؤشر.
4. يعطي حكماً: `pass` / `review` / `fail`.
5. يقترح بديلاً لكل موضع.

**ما لا يفعله:** لا يفهم السياق. `من خلال النافذة` قد تكون حرفية صحيحة (من خلال الفتحة). لذلك:

- **المخالفة القاطعة** يُعاد النظر فيها يدوياً قبل الرفض.
- **المخالفة العالية** تُقبل إن كان التركيب حرفياً حقيقياً.
- لا يُستبدل نصٌّ آلياً بلا قراءة.

## ٤. البدائل العملية

| العرنجية | البديل | الملاحظة |
| :--- | :--- | :--- |
| `من خلال المفاوضات` | `بالمفاوضات` / `في المفاوضات` | `من خلال` للفُرجة الحقيقية فقط |
| `على صعيد الاقتصاد` | `في شأن الاقتصاد` / `في الاقتصاد` | الصعيد وجه الأرض |
| `بالنسبة لي` | `عندي` / `في رأيي` | تركيب هجين |
| `في إطار الخطة` | `في الخطة` / `ضمن الخطة` | الإطار للصورة |
| `قام بزيارة` | `زار` | الفعل المساعد فارغ |
| `أجرى فحصاً` | `فحص` | المصدر المفعول يحمل الفعل |
| `لعب دوراً` | `أسهم` / `كان له أثر` | الاستعارة مسطّحة |
| `شكّل خطراً` | `هدّد` | الفعل أقوى |
| `أعطى وعداً` | `وعد` | الاشتقاق المباشر |
| `حيث أن` | `لأن` / `إذ` | `حيث` ظرف مكان |
| `كونه غير مستوفٍ` | `لأنه لم يستوفِ` | `كونه` ترجمة being |
| `مما أدى إلى` | `فنتج عن ذلك` / `فـ` | فاء السببية |
| `في نهاية المطاف` | `آخر الأمر` / `في مآله` | تعبير مترجم |
| `أخذ بعين الاعتبار` | `راعى` / `التفت إلى` | استعارة مترجمة |
| `تبنّى فكرة` | `استحسن الفكرة` / `أخذ بها` | التبني للولد |
| `الأكثر أهمية` | `الأهم` | أفعل التفضيل |
| `تم توقيع… من قبل` | `وقّع فلان…` | المجهول مع فاعل معلوم |
| `بواسطة` | `بـ` | الباء تكفي |

## ٥. الاستثناءات

لا تُصحح ما ليس عرنجية:

- **`من خلال النافذة`** حرفية: الفتحة التي منها النظر.
- **`على صعيد`** إذا كان الصعيد أرضاً حقيقية.
- **`في إطار`** إذا كان إطاراً مادياً.
- **`بشكل`** إذا كان الشكل جسماً (`بشكل مثلث`).
- **`المصطلح المستقر`**: الشيوعية، الاشتراكية، البيروقراطية، الثقافة. لا تُستبدل بمقابل قاموسي غريب.
- **`تم`** ليست خطأً دائماً: `تم الاتفاق` مقبولة. الخطأ هو `تم … من قبل فلان` مع فاعل معلوم.

**القاعدة:** العرنجية ليست كل كلمة حديثة، بل **البنية التي تُنسخ من لغة أخرى**. النقد للتركيب، لا للحداثة.

## ٦. علاقة البوابة بالتحرير

| الوضع | ما تفعله البوابة |
| :--- | :--- |
| `proofread` | تفحص، ولا تُغيّر ما ليس خطأً نحوياً |
| `edit` | تُصلح العرنجية بوسم `style` |
| `rewrite` | تُعيد البناء، مع حفظ الصوت |
| `translation-review` | تُطبّق البوابة بعد الأمانة، لا قبلها |

**القاعدة:** لا تُصلح العرنجية على حساب المعنى. إن كان البديل يغيّر المعنى، فاترك الأصل واذكره في `unresolved`.

## ٧. قائمة فحص

- [ ] هل النص خالٍ من `قام بـ` و`أجرى` و`لعب دوراً`؟
- [ ] هل حُذف `من قبل` و`بواسطة` حين عُلم الفاعل؟
- [ ] هل نُقّيت `من خلال` و`على صعيد` و`في إطار` و`بالنسبة لـ`؟
- [ ] هل استُعمل الفعل المباشر بدل المصدر المساعد؟
- [ ] هل استُعملت صيغ التفضيل المباشرة؟
- [ ] هل المصطلح المستقر بقي على حاله؟
- [ ] هل كل استثناء مبرَّر بالسياق؟
- [ ] هل المؤشر تحت العتبة، أم أن النص يحتاج إعادة بناء؟

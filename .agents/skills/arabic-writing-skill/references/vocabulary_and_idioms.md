# معجم الألفاظ والتعابير العَرَنْجِيَّة وبدائلها الفصيحة
> ملحق مرجعي لمهارة: `arabic-writing-skill` مستخلص من كتاب «العَرَنْجِيَّة» لأحمد الغامدي.

---

## ١. الأفعال وتراكيب التعدية

| التعبير العرنجي الهجين ❌ | الأصل الإفرنجي المقابل | الصواب العربي الفصيح الأصيل ✅ | الشاهد النحوي والبياني |
| :--- | :--- | :--- | :--- |
| **أكد على** أهمية الأمر | to emphasize on (calque) | **أكّد** الأمرَ / **أكّد** أهميةَ الأمر | الفعل "أكّد" يتعدى بنفسه إلى المفعول به ولا يحتاج إلى حرف الجر "على". |
| **ركّز على** النقطة | to focus on | **عُنيَ بـ**الأمر / **قَصَرَ همَّه على** كذا / **أقبل على** | التركيز في لغة العرب غرس الرمح في الأرض؛ واستعماله للنظر والاهتمام عجمة. |
| **أجاب على** السؤال | to answer to (calque) | **أجابَ** السؤالَ / **أجابَ عن** السؤال | العرب تقول: أجابه إلى حاجته، وأجاب السؤالَ أو عن السؤال، ولا تقول "أجاب عليه". |
| **اعتذر له** | apologized to him | **اعتذر إليه** | العرب تعدي الاعتذار بـ "إلى" إذا كان للمعتذر إليه، وبـ "عن" للذنب، وبـ "من" للجرم. |
| **أشار إلى أنه** | indicated that | **أشار إلى** كذا / **أوْمَأ إلى** / **بيّنَ أنَّ** | الإشارة باليد أو الطرف الحسي؛ وعند التوضيح يُقال: "وبيّن أن" أو "وذكر أن". |
| **شارك مع فلان** | participated with | **شارك فلاناً** | صيغة "فاعل" متعدية بذاتها إلى المفعول الأول: "شاركتُ زيداً في الأمر". |
| **تشاركوا مع بعضهم** | shared with each other | **تشاركوا** / **تقاسموا** | صيغة "تفاعل" تقتضي التعدد والمشاركة وتستغني كلياً عن "مع بعضهم". |
| **تحدث مع زيد** | spoke with Zayd | **حادثَ زيداً** / **كلّم زيداً** | لا داعي لحشو "مع"؛ فالمحادثة والمكالمة تتعديان بنفسهما. |
| **جعله يضحك / ينام** | made him laugh / sleep | **أضحكَهُ** / **أنَامَهُ** (أو **نوّمه**) | استخدام صيغة "أَفْعَلَ" أو "فَعَّلَ" للتعدية السببية المباشرة دون الاستعانة بـ "جعل". |
| **أعطى وعداً** | made a promise | **وعَدَ** | نبذ الأفعال المساعدة؛ الفعل الصريح المشتق أبلغ وأخصر. |
| **قام بدراسة** | carried out a study | **دَرَسَ** / **استقصى** / **بحث** | إماتة الفعل المباشر بالاستعانة بـ "قام بـ" عجمة ظاهرة. |
| **شكّل خطراً / عائقاً** | formed / posed a threat | **كان خطراً** / **هدّد** / **عاقَ** | "شَكّلَ" في العربية من التشكيل والصور والحِلى، ولا يُقال شكل خطراً. |
| **لعب دوراً** | played a role | **كان له أثرٌ** / **نهض بأمر** / **بلى بلاءً حسناً** | لا دور ملعوب في جدّيات الأمور؛ وهو تشبيه مترجم من التمثيل المسرحي الغربي. |
| **نال إعجاب فلان** | won his admiration | **أعجبَ فلاناً** / **راقَ له** | الفعل المتعدي: "أعجبني الشيءُ" ولا حاجة لتركيب "نال إعجابي". |
| **وجد نفسه مضطراً** | found himself forced to | **أُلجئ إلى** / **اضطُرّ إلى** / **حُمِلَ على** | ترجمة حرفية سمجة لـ "found himself"; العرب تعبر بالبناء للمجهول للأمر القهري. |

## ٢. الأسماء والاستعارات والنعوت المترجمة

| اللفظ العرنجي المستورد ❌ | الأصل الإفرنجي المقابل | الصواب العربي الفصيح والبدائل البيانية ✅ |
| :--- | :--- | :--- |
| **تبنّى فكرة / مشروعاً** | to adopt an idea | **استحسن** / **ارتضى** / **أخذ به** / **أقرّه** (التبني في العربية لدعوة الولد لغير أبيه). |
| **عكس مشاعره / واقعه** | to reflect feelings | **أظهرَ** / **أبانَ عن** / **أوضحَ** / **جلّى** / **حكى** (العكس هو القلب والرد). |
| **تحديات** | challenges | **شدائد** / **مكاره** / **صعاب** / **عقبات** / **مآزق** / **أزمات** / **خطوب**. |
| **شفافية** | transparency | **وضوح** / **نزاهة** / **علانية** / **صدق** / **براءة من الدغل والشبهة**. |
| **محوري** | pivotal / core | **رئيس** / **قطب الرحى** / **عماد الأمر** / **أصيل** / **مدار الأمر**. |
| **حجر زاوية** | cornerstone | **أساس البنيان** / **مِلاك الأمر** / **عِماده الأوثق**. |
| **ضوء أخضر** | green light | **إذنٌ** / **ترخيصٌ** / **تسويغٌ** / **إجازةٌ** / **تخلية بينه وبين شأنه**. |
| **قنبلة موقوتة** | ticking time bomb | **شرٌّ مستطير** / **داهيةٌ دهياء** / **بلاءٌ محدق**. |
| **غسيل دماغ** | brainwashing | **سحر العقول** / **استهواء** / **إغواء** / **فتنة**. |
| **وجهة نظر** | point of view | **رأيٌ** / **مذهبٌ** / **نظرٌ** / **ما أراه**. |
| **على نفس الصعيد** | on the same level | **في هذا السياق** / **في هذا الباب** / **في الشأن نفسه** / **ومثله**. |
| **على صعيد الوزارة** | on the ministry level | **عند الوزارة** / **في ديوان الوزارة** / **في شأن الوزارة**. |
| **في نهاية المطاف** | at the end of the day | **في عاقبة الأمر** / **في مآله** / **آخِراً** / **في خاتمة المطاف**. |
| **خطوة بخطوة** | step by step | **شيئاً فشيئاً** / **رويداً رويداً** / **تدرجاً** / **درجة فدرجة**. |
| **استثنائي** | exceptional | **منقطع النظير** / **فريد** / **نسيج وحده** / **فذّ** / **عجيب**. |
| **بشكل كبير / بصورة ملحوظة** | significantly / noticeably | **كثيراً جداً** / **ظهوراً بيناً** / **أثراً جلياً** (استعمال المفعول المطلق المبين للنوع). |
| **الأكثر أهمية / الأكثر حباً** | more / most important | **الأهمُّ** / **الأحبُّ** (استعمال وزن أفعل التفضيل المباشر). |
| **تغطية إعلامية / مالية** | media coverage / expenses | **بثّ الخبر ونقله** / **إيفاء النفقات والتكفل بها**. |
| **إيجابيات وسلبيات** | pros and cons / positive | **محاسن ومساوئ** / **فضائل ومثالب** / **منافع ومضار** / **تفاءل واستبشر**. |
| **حمية غذائية** | diet | **حِمْيَة** (الحمية في لغة العرب لا تكون إلا في الغذاء، فلا حاجة لوصفها بغذائية). |

## ٣. حروف المعاني وأدوات الربط والسياق

| الأسلوب العرنجي ❌ | الصواب العربي الفصيح ✅ | التوجيه اللغوي |
| :--- | :--- | :--- |
| فُعِلَ كذا **بواسطة** فلان | فَعَلَ فلانٌ كذا / تم على يد فلان | نبذ "بواسطة"؛ واستعمال حرف "الباء" أو ذكر الفاعل الصريح. |
| تحقّق النجاح **من خلال** الصبر | تحقّق النجاح **بـ**الصبر / **في** الصبر | "من خلال" معناها وسط الفُرجة المادية الحقيقية؛ والاستعانة تكون بالباء. |
| عقار طبي **ضد** السعال | عقارٌ **لـ**لسعال / **يبرئ من** السعال | "ضد" ليس حرف جر ولا أداة دفع للمرض؛ بل الدواء للعلة أو الشفاء منها. |
| سافر **كنوع من** التغيير | سافر **طلباً لـ**ـلتغيير / **ترويحاً عن** النفس | تركيب "كنوع من" ترجمة ركيكة لـ "as a kind of". |
| اعتذر **حيث أن** سيارته تعطلت | اعتذر **لأنّ** سيارته تعطلت / **إذْ** تعطلت | "حيث" ظرف مكان، وتلوها بأن المشبهة بالفعل من أقبح اللحن المولد. |
| فُصِلَ من العمل **كونه** أهمل | فُصِلَ **لإهماله** / **لأنه** أهمل | استعمال "كونه" ترجمة حرفية لمصدر الكينونة الإنجليزي Being. |
| صمت **مما أدى إلى** غضبه | صمت **فـ**ـأغضبه ذلك / **فغضب** | الفاء السببية في العربية تغني عن تراكيب العرنجية المطولة. |
| جلس **لمدة** ثلاث ساعات | جلس **ثلاثَ** ساعاتٍ | الظرف منصوب بتقدير "في" دون حاجة لإقحام "لمدة" أو "لفترة". |
| أتى **في عام** 1990م | أتى **سنةَ** 1990م / **عامَ** 1990م | حذف حرف الجر "في" لأن السنة والعام ظرف زمان منصوب بذاته. |
| لا تذهب، **حيث لا يجب** فعل ذلك | لا تذهب، **فلا يحلّ** لك ذلك / **ولا ينبغي** | ترجمة You should not do that؛ والصواب النهي الصريح أو بيان الامتناع. |
